# Actualización de disponibilidad comercial

- **TERO Security:** único producto marcado como «Próximamente», tanto en catálogo como en presupuestador. No seleccionable para compra.
- **CHAJÁ y Golondrina:** disponibles para consultas, evaluación técnica y presupuestos por encargo.
- **Automatización y robótica a medida:** servicios disponibles para solicitar y presupuestar.
- Se conserva el aviso de desarrollo, validación y seguridad industrial. «Disponible para solicitar» no implica hardware certificado ni instalación industrial habilitada.
- Las funciones de simulación web siguen siendo demostrativas.

Verificar `npm ci`, `npm run lint` y `npm run build` antes de publicar.
